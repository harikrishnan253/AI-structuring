## Three-File Fix

### Fix 1 — ingestion.py (primary)
After the `numPr` try/except block (after line 643), before the indentation
check (line 645), add style-name inference for the no-numPr case.
This mirrors the identical check inside the numPr block (lines 634-637):

```python
# Style-name-based list inference for paragraphs that use named list styles
# without XML numbering properties (numPr absent). Catches publisher templates
# using "List Bullet", "BulletList*", "List Number", "NumberList*", etc.
# NOTE: The same bullet/number keyword check already runs inside the numPr
# block above (lines 634-637) for the numPr-present case. This is its mirror.
if not metadata.get('has_bullet') and not metadata.get('has_numbering') \
        and not metadata.get('has_xml_list'):
    _sn = metadata.get('style_name', '').lower()
    if 'bullet' in _sn:
        metadata['has_bullet'] = True
    elif 'number' in _sn:
        metadata['has_numbering'] = True
```

No change to the numPr block (XML behaviour unchanged).

### Fix 2 — blocks.py (defence-in-depth)
Add `style_name`-based fallbacks so that even if ingestion misses a case,
blocks still classifies the paragraph correctly.

**2a** `_is_list_item()` — after the mnemonic heuristic (after line 91):
```python
# Style-name fallback for style-only lists
_sn = metadata.get("style_name", "").lower()
if _sn and ("bullet" in _sn or "number" in _sn):
    return True
```

**2b** `_list_kind()` — after the mnemonic branch (after line 104):
```python
# Style-name fallback
_sn = metadata.get("style_name", "").lower()
if _sn:
    if "bullet" in _sn:
        return "bullet"
    if "number" in _sn:
        return "numbered"
```

**2c** `_enrich_list_metadata()` candidate check — add one OR-clause (line 251):
```python
is_candidate = (
    meta.get("has_bullet")
    or meta.get("has_numbering")
    or meta.get("has_xml_list")
    or meta.get("xml_list_level") is not None
    or bool("bullet" in meta.get("style_name","").lower()
            or "number" in meta.get("style_name","").lower())
)
```

### Fix 3 — reconstruction.py (root fix for STRUCTURE_GUARD_FAIL)

(style-based lists only), so the exception is not needed — list semantics must win.

**Remove** lines 664-665:
